# WVU Cardiogenic Shock Line

One-tap referral page for referring clinicians.

- Call **MARS (304) 598-6000** → **1** (auto-sent) → ask for **Cardiology Blue** (Advanced Heart Failure)
- Criteria + SCAI C+ guidance from the WVU HVI activation flyer
- Add to Home Screen for phone icon access
